===========================================
🔧 라우팅 설정 방법
===========================================

1. 서비스메뉴 라우팅:
   - 파일: UserServiceMenu.jsx
   - 각 메뉴 아이템에 path 속성 추가
   - JihunRoute.jsx에 해당 경로 추가 필요

2. 충전 버튼 라우팅:
   - 파일: UserProfileCard.jsx
   - handleChargeClick 함수 주석 해제
   - navigate('/cm-charge') 경로 설정

3. 헤더 버튼 라우팅:
   - 파일: UserMainHeader.jsx
   - 알림: navigate('/notifications')
   - 설정: navigate('/settings')
   - 로고: navigate('/')

4. 네비게이션 라우팅:
   - 파일: UserMainNavi.jsx
   - 홈: "/"
   - 검색: "/search"
   - 선물: "/gifts"
   - 가맹점: "/franchises"

===========================================
📝 수정 가이드
===========================================

1. 서비스메뉴 아이템 추가/제거:
   - UserServiceMenu.jsx의 serviceItems 배열 수정

2. 버튼 텍스트/아이콘 변경:
   - 각 컴포넌트 파일에서 주석 처리된 부분 참고

3. 라우팅 경로 변경:
   - 각 컴포넌트의 path 속성 수정
   - JihunRoute.jsx에 해당 라우트 추가
